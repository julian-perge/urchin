# Keep the aspect ratio when the window is resized instead of stretching like the original

The original fills whatever area it's given and distorts to do it: `frame_1/DoAction.as:4515` sets `Stage.scaleMode = "exactFit"`. The port keeps every element in proportion, because `project.godot` sets `display/window/stretch/mode` to `canvas_items` and leaves `display/window/stretch/aspect` at Godot's default, `keep`. A window that isn't 4:3 gets black bars instead, so a maximized 1920x1080 window shows a 1440x1080 picture, and a player of the original will notice that it no longer fills the screen. Matching the original would only take setting the aspect to `ignore`. The project owner's call on [Where should the SWF-derived screen rects live?](https://github.com/julian-perge/urchin/issues/117) was that correct proportions at bigger resolutions are a quality improvement over copying the distortion.

AS paths are relative to `dev/source_files/action_script/`. The claim about the original comes from the ActionScript, and the claim about the port comes from its settings and Godot's documented default, not from running either one maximized.
